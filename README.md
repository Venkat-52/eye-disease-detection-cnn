# eye-disease-detection-cnn
eye-disease-detection-cnn

**Eye Disease Detection using Deep Learning**

**Project Overview**
This project uses Deep Learning and Convolutional Neural Networks (CNN) to detect eye diseases from retinal images.

The system classifies retinal images into:
1. Cataract
2. Diabetic Retinopathy
3. Glaucoma
4. Normal

**Technologies Used**
1. Python
2. TensorFlow
3. Keras
4. CNN
5. Google Colab
6. Deep Learning

**Dataset**
Dataset used:
Eye Disease Classification Dataset from Kaggle
