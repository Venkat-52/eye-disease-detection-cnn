# Eye Disease Detection using Deep Learning

## Project Overview
This project uses Deep Learning and Convolutional Neural Networks (CNN) to detect eye diseases from retinal images.

The system classifies retinal images into:
1. Cataract
2. Diabetic Retinopathy
3. Glaucoma
4. Normal

## Technologies Used
1. Python
2. TensorFlow
3. Keras
4. CNN
5. Google Colab
6. Deep Learning

## Dataset
Dataset used:
Eye Disease Classification Dataset from Kaggle

Classes:
1. Cataract
2. Diabetic Retinopathy
3. Glaucoma
4. Normal

## Model Performance
1. Accuracy: 92%
2. Precision: 83.31%
3. Recall: 83.31%
4. F1 Score: 83.31%
5. AUC Score: 0.95

## Features
1. Automated eye disease prediction
2. CNN-based image classification
3. Early disease detection support
4. Medical image analysis
